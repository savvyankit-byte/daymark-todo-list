# Daymark To-do List

A lightweight, responsive to-do list that runs directly in your browser. It is built with plain HTML, CSS, and JavaScript, with no dependencies or build step.

## Run

Open `index.html` in a web browser. No server or installation is required.

## Features

- Add tasks and mark them complete or active.
- Filter the list to show all, to-do, or completed tasks.
- Delete individual tasks or clear all completed tasks.
- Save tasks in browser local storage so they remain after reloading the page.
- Responsive layout with keyboard-accessible controls.

## Data

Tasks are stored in the browser's local storage for this page. They are not synced between browsers or devices. Clearing the browser's site data can remove saved tasks.
